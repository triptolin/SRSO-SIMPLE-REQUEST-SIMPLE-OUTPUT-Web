# SRSO-SIMPLE-REQUEST-SIMPLE-OUTPUT-Web

## Version
**0.1**

## Описание проекта

SRSO (Simple Request Simple Output) — простой язык программирования, созданный для упрощения разработки веб-сайтов и облегчения процесса верстки.

Язык предназначен для быстрого создания веб-страниц и обработки простых веб-запросов. По концепции SRSO похож на PHP, но имеет более простой синтаксис и ориентирован на удобную разработку веб-интерфейсов.

## Возможности версии 0.1

В текущей версии реализована базовая система токенизации (Lexer).

Lexer выполняет:
- анализ исходного кода;
- поиск ключевых слов;
- определение операторов;
- создание токенов для дальнейшей обработки.

## Реализованные токены

Поддерживаются следующие типы токенов:

- `KEYWORD_INT` - целочисленный тип данных
- `KEYWORD_FLOAT` - число с плавающей точкой
- `KEYWORD_BOOL` - логический тип данных
- `KEYWORD_STRING` - строковый тип данных
- `KEYWORD_IDENTIFER` - идентификаторы переменных
- `KEYWORD_NAME` - имена
- `ASSIGN` - оператор присваивания
- `PLUS` - оператор сложения
- `MINUS` - оператор вычитания
- `SEMICOLON` - завершение выражения
- `UNKNOW` - неизвестный токен
- `SOF` - начало файла
- `EOF` - конец файла
